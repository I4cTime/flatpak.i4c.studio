I4C Flatpak Repository

Signed builds of I4C Studio desktop apps. Add the remote once — updates arrive with flatpak update like everywhere else.

Add the repository

flatpak remote-add --user --if-not-exists i4c https://flatpak.i4c.studio/index.flatpakrepo

Apps

ProtonShift io.github.i4ctime.protonshift

Configure Proton, gamescope, MangoHud and your Steam library — desktop and Steam Deck.

flatpak install i4c io.github.i4ctime.protonshift

Trust

Every build is compiled from a pinned, tagged commit of the public source repository by GitHub Actions and GPG-signed. The .flatpakrepo file carries the public key.
